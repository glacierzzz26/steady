## 设计

核心决策（详见[定稿设计](../design/因子研究闭环.md)）：

1. **IC 单实现（§4.1/§4.2，研究地基）**：Rank IC = 横截面 Spearman（`factor_value.normalized`@T，`adj_close[T+H]/adj_close[T]-1`@T→T+H），因子值 as-of T、收益严格在 T 之后（**无未来函数**）。全部统计数学收在 **quant-engine（Python/pandas）单实现**预计算 `factor_stat`/`factor_corr`；Go 只做**读表 + 轻聚合**（mean/std/比值/矩阵平均）。避免两套 IC 实现漂移导致 FactorLab 与 2.3b 试算数字不一致。
2. **预计算写库（幂等追加）**：`factor_stat` 按 `(factor_name, trade_date)` upsert（5 档 IC + 5 分层组均），`factor_corr` 按 `trade_date` upsert（**6×6 规范序**矩阵，per-date；缺数据的因子列为 NULL）。IC 尾部因前向收益未走完为 NULL（正常，数据补齐重跑即填）。
3. **ICIR = mean(IC)/std(IC)**（总体标准差 ddof=0，不年化），与 Python 逐位一致；样本 <5 或 std=0 → NULL。
4. **单调性** = Q1 跑赢 Q5 的交易日占比（胜率 0-1）。
5. **NULL 纪律**：FactorStat 的 IC/Q 列用 `*float64`，NULL→nil（非 0.0），聚合跳过 nil，防止污染均值/矩阵平均。
6. **区间约束**：horizon ∈ {1,5,10,20,60}、start≤end、区间 ≤5 年（防超大请求）。

## 验收

- ✅ **Go 单测**：`go test -p 1 ./internal/...`（TEST_DB_DSN 门控）**全绿**——`factor_stats_test.go`（IC 聚合已知值 ic_5d=[0.1..0.5]→mean=0.3/std=√0.02/icir=0.3/√0.02、衰减、分层、单调性 0.8、空态、校验、矩阵平均含 nil）、`factor_route_test.go`（路由 smoke：stats 元数据 + ic_series + icir 空守卫 + correlation 6 因子 + 404/400 映射）。
- ✅ **Python 单测**：`test_factor_research.py` **10 passed**——合成数据断言 Rank IC=±1（Spearman 满相关）、并列秩与参考 Spearman 一致、ICIR 已知值、分层单调递减、相关性已知矩阵、预计算行组装（幂等、恒 6×6、NULL 因子）。
- ✅ **全链路契约 e2e**（本页最关键的验证，抓到 2 个集成 bug）：真实 postgres（init.sql+002 迁移）→ Python 预计算写库 → **Go 服务读聚合**，手工核对一致：
  - ma_trend：ic_1d=1.0×5、ic_5d=1.0×1、分层 Q1=0.5 / Q2=0.4167 / Q3=0.3571 / Q4=0.3125 / Q5=0.2639、单调性=1.0（Q1 全胜 Q5）
  - pe_ratio：ic_1d=-1.0×5（方向正确，正 IC=因子方向对）
  - 相关矩阵：ma×ma=1.0、ma×pe=-1.0、未种子因子全 NULL（nil 格平均跳过）
  - **抓到 bug 1（列名漂移）**：GORM 默认命名 `IC5D`→`ic5_d`，与生产 schema `ic_5d` 不符——测试库由 AutoMigrate 建表两端一致故测试漏过；对真实 schema 读全 NULL。已修：FactorStat IC/Q 全加显式 `column:` tag。
  - **抓到 bug 2（matrix 双重编码）**：Python 写 factor_corr 时 `json.dumps(matrix)` 成字符串再交给 SQLAlchemy JSON 列 → 二次序列化存成 JSON 字符串（外层带引号），Go `json.Unmarshal` 到 `[][]*float64` 失败全 nil。已修：matrix 传 Python 列表（None→JSON null），SQLAlchemy 序列化一次。**两 bug 均在部署前抓到，生产无脏数据需修**（生产库尚无 factor_stat/factor_corr 表）。
- ✅ **前端**：`tsc --noEmit` + `vite build` 通过（FactorLab 全量接通真实 API，mock 数据移除，仅剩设计诚实空态）。
- ⚠️ **浏览器实渲染未在本环境执行**：数据链路（预计算→Go→前端数据契约）已 e2e 全通；开发栈未运行（5432 被占），真实点亮留待部署后 `dev-up.sh` 环境验证。
