## 第一阶段归档说明

**"第一阶段"指 frontend-v2 之前的全部开发**：搭框架 → 部署/数据源 → 通知 → 可靠性 → LLM。对应五页归档文档 + 一页维护记录，全部在 [`phase1/`](phase1/README.md)（`design/` + `stages/`），已归档冻结。

> 关于编号与执行顺序的交错：Iteration 编号沿用 `优化路线图.md` 的推荐顺序（0 部署 → 1 飞书 → 2 可靠性），但**实际执行顺序是 飞书通知（08-21 凌晨）→ 部署基线（08-21 晚）→ 数据源（08-22）→ 可靠性（08-22）**——飞书先做是为了部署时能观测。首个生产基线 `c8d0651` 实际同时包含 飞书 + 部署 两个迭代的成果。
