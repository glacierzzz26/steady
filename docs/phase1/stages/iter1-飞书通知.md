## 设计

1. **统一通知模块**：Python 侧 `quant-engine/app/notify.py` + Go 侧 `backend/internal/service/notify.go`。支持 webhook 签名校验、请求超时、有限重试；**推送失败只记日志，不阻塞主业务**；webhook 地址脱敏日志。
   > 与规划的差异（如实记录）：原规划 `backend/pkg/notify/notify.go`，实际放 `internal/service/notify.go`，规划路径未采用。
2. **配置全部 `app_config.feishu.*`**（页面「设置」可改、存库、不读环境变量）；`init.sql:380-388` 种子 8 个 `notify_config` 事件。
3. **两类推送**：
   - 定时：信号 / 自动交易结果 / 净值 / 日报 / 数据质量 / 早报，触发时间由 `notify_config` 表配置；
   - 事件：回测完成、任务失败告警、手动触发。
4. **每日汇总日报**：`quant-engine/app/notify_scheduler.py` 在 21:00 事件统一生成并推送，内容汇总信号 / 交易 / 净值（`_daily_report_content`，`notify_scheduler.py:155`）。
5. **"该做没做"监控**：每分钟通知 tick 查 `task_run` 台账，定时任务到点没执行（宽限 30 分钟）→ 推红色"任务未执行"告警；当日有任务失败同样推红色告警。
6. **@所有人开关**：`feishu.at_all` 配置，Python/Go 卡片注入 `<at id="all">`。
